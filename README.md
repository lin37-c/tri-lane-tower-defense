# 三路塔防 · Tri-lane Tower Defense

**▶ 在线试玩：https://lin37-c.github.io/tri-lane-tower-defense/**

三条路、四种塔、24 波的塔防原型。固定预算布防，塔按第 4 / 9 / 14 波依次解锁。

单文件网页，浏览器直接打开即玩，不需要构建、不需要依赖。

## 怎么玩

- 点塔型 → 点塔位建造；点已有塔 → 升级或拆除（返还 60%）
- 空格暂停，1–4 选塔，Esc 取消
- 波前常驻「下一波构成」，锁定的塔卡会显示「第 N 波解锁」

调试入口：`?test=1` 跑 4 套固定策略与 22 条边界断言，`?demo=1` 自动铺塔并预跑 10 秒，`?gallery=1` 展示五种敌人。

## 设计要点

- **每一波都有解**：玩家的失败来自取舍，不来自被设计成必死的波次
- **台阶式难度**：新兵种首现时数量压低，之后逐波加压，单波不陡增
- **护甲用减法**：`实际伤害 = max(1, 单发 − 护甲)`。箭塔 L1 打 12 护甲的甲兵，每秒伤害从 13.3 掉到 1.7，这是「必须换塔」的时刻；到 L3 单发 18 才回到 10.0
- **预算即取舍**：全歼总金币 2263，16 个塔位全升满需 1900–2600，凑不齐
- **首领护甲 16** 故意卡在箭塔 L1（8）与 L3（18）之间，让升级后的箭塔也能参与打首领，而不是只有毒塔能打

## 我的职责

玩法规则、数值取舍、验收标准由我确定；代码实现借助 AI 工具完成。我做的是设计决策、实玩验证与判断——例如完整试玩后发现前 23 波偏松、首领打不动，判断原因不是首领血量而是护卫跑得比首领快、塔一直在打护卫，于是减护卫并把首领从 1000 血 / 护甲 24 调到 480 / 16。
